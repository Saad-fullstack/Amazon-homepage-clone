🛒 Amazon Homepage Clone
A simple and responsive **Amazon homepage clone** built using **HTML and CSS**.
This project is designed to practice layout design, flexbox, and real-world UI structure.

🚀 Live Preview
https://amazon-homepage-clone-z7dw.vercel.app/

## 📌 Features

* ✅ Fully structured Amazon-like layout
* ✅ Responsive navigation bar
* ✅ Search bar with styling
* ✅ Product grid section (shop section)
* ✅ Hero banner section
* ✅ Multi-column footer
* ✅ Hover effects for better UI experience

🛠️ Technologies Used
* HTML5
* CSS3 (Flexbox)
